# portfolio-skills

A personal set of AI agent skills for product design work. These are used with Cursor and Claude to accelerate and standardise common design and product workflows.

## Skills

### design-critique
Runs a structured design critique on a UI screenshot, Figma frame, or described interface. Covers usability, information hierarchy, consistency, actionability, and edge cases.

### risk-assessor
Scores a product initiative across 8 risk dimensions to produce an overall risk level. Clinical Risk is a veto dimension. Useful at the start of discovery to calibrate how much validation is needed before committing to build.

### user-story
Creates development-ready user stories in a structured template for healthcare product work. Follows the Mike Cohn format with sections for background, problem, impact, proposed solution, acceptance criteria, and QA scenarios.

## Usage

Point your AI agent at the relevant `SKILL.md` file and it will follow the workflow defined inside.
